# Glossary

## Proposals

**Proposal**
A vote that runs on the modular-governance programs on Solana. Each Network's Organization owns its Proposals.

**Realm Proposal**
A vote that ran on SPL Governance (Realms) after the move to Solana and before modular governance. The results are fixed and are kept as a static record.

**Legacy Proposal**
A vote that ran on the Helium L1 blockchain before the move to Solana. Every Legacy Proposal is an HNT vote. Its ID is a base58 L1 address, not a Solana key.

**Network**
One of `hnt`, `mobile` or `iot`. A Network selects which Organization's Proposals and which token's Positions the user sees.
